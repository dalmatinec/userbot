# Userbot + админка в боте

Юзербот на Telethon и бот-админка на aiogram 3. Оба работают в одном процессе и
хранят данные в SQLite (режим WAL, индексы под каждый частый запрос).

## Что умеет

**🛰 Группы.** Сюда добавляются группы и каналы, куда ваш бот пересылает
заявки. У каждой группы свои настройки:
- 🟢/🔴 включить или выключить отслеживание одной кнопкой;
- ⏳ задержка реакции: сразу, 10, 20, 30, 40, 50 или 60 секунд. Это пауза перед
  ответом в группе, ЛС автору и пересылкой. Уведомление в бот приходит сразу;
- 🔔 уведомления из этой группы: да или нет;
- 🎯 свои фильтры: команды, ключевые слова или любое сообщение. Фильтры
  создаются прямо на экране группы, каждый включается и выключается кнопкой ⏯.

**🎯 Фильтры.** У каждого фильтра свой триггер и свои действия.

Триггеры:
- ⌨️ **свои команды**: `/start`, `/price`, `/help`, `старт`, `меню` и т.д.
  Команды со слэшем находятся в любом месте текста (в том числе `/start@bot` и
  «Пользователь написал: /start»). Команды без слэша — когда сообщение
  начинается с этого слова;
- 🔑 **ключевые слова**: город, товар или город и товар вместе. Слова одной
  группы связаны условием «ИЛИ», а группы между собой — «И». Есть минус-слова,
  поиск по началу слова (`москв` находит «Москве»), слово целиком (`"спб"`) и
  регулярные выражения (`re:...`);
- 📨 **любое сообщение**.

Один фильтр можно подключить сразу к нескольким группам.

Что делать при совпадении, настраивается для каждого фильтра отдельно:
- 🔔 прислать карточку заявки в бот-админку. В карточке есть кнопки «✉️ Написать
  автору шаблоном» и «🔗 Открыть сообщение»;
- ↪️ переслать заявку в выбранный чат;
- 💬 ответить шаблоном прямо в группе;
- ✉️ написать автору в личку шаблоном. Одному человеку пишется не чаще раза в N
  часов. ЛС уходят через очередь с паузой между сообщениями.

Автора заявки юзербот ищет так: сначала в пересланном сообщении, затем по
упоминанию, по `tg://user?id=`, по `@username` или `id: 123` в тексте.

**📝 Шаблоны.** Отправьте боту сообщение в том виде, в каком оно должно
выглядеть. Форматирование сохраняется полностью, включая спойлеры, цитаты и
премиум-эмодзи. К тексту можно приложить фото, видео, GIF, файл, аудио или
голосовое. У шаблона есть предпросмотр и тестовая отправка в «Избранное».

**📣 Рассылки.** Шаблоны отправляются в выбранные группы и каналы, куда аккаунт
может писать:
- вручную или по расписанию (раз в N минут или часов);
- с паузой между чатами: 10, 20, 30, 40, 50, 60 секунд или своё значение; пауза слегка случайно меняется;
- если шаблонов несколько, они чередуются.

Есть тихие часы, отчёт об ошибках и остановка на ходу. FloodWait и медленный
режим обрабатываются. Чаты, куда писать нельзя, помечаются автоматически.

**💬 Чаты.** Список групп и каналов аккаунта с поиском, фильтром по типу и
выбором «все / ничего».

**Меню.** Основные разделы стоят в главном меню, второстепенные — под кнопкой
**«➕ Ещё»**: статистика, настройки, аккаунт, админы. Что куда попадает, можно
поменять в «Ещё → 🎛 Настроить меню».

## ⚠️ Про сессию (важно)

Файл или строку сессии, на которой уже работает ваш первый бот, использовать
**нельзя**. Если одна сессия работает в двух программах одновременно, Telegram
сбросит её (`AUTH_KEY_DUPLICATED`), и отвалятся оба бота.

Для этого юзербота создаётся **новая сессия**, то есть ещё одно «устройство» на
том же аккаунте. `API_ID` и `API_HASH` берутся те же. Первый бот при этом
продолжает работать.

## Установка на сервер

Нужен Python 3.10 или новее.

```bash
cd /opt
git clone https://github.com/dalmatinec/userbot.git
cd userbot
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

cp .env.example .env
nano .env            # API_ID, API_HASH, BOT_TOKEN нового бота, ADMIN_IDS

.venv/bin/python login.py   # телефон → код из Telegram → пароль 2FA (если есть)
.venv/bin/python main.py    # проверочный запуск: откройте бота и нажмите /start
```

Если сессию удобнее хранить строкой: `python login.py --string`, затем вставьте
результат в `SESSION=` в `.env`.

### Автозапуск (systemd)

```bash
sudo useradd -r -s /usr/sbin/nologin userbot
sudo chown -R userbot:userbot /opt/userbot
sudo cp deploy/userbot-admin.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now userbot-admin
journalctl -u userbot-admin -f      # логи
```

Сервис полностью независим от первого бота: у него свои папка, сессия, база и
процесс.

## Быстрый старт в админке

1. **💬 Чаты → 🔄 Обновить** — подтянуть группы и каналы аккаунта.
2. **📝 Шаблоны → ➕** — создать ответы и посты.
3. **🛰 Группы → ➕ Добавить группу** — выбрать группу, куда приходят заявки.
   На экране группы:
   - выставить ⏳ задержку;
   - нажать **➕ Команды** и вписать свои, например `/start, /price`;
   - или **➕ Ключевые слова** (например, группа 1: `москв, мск`; группа 2:
     `айфон, iphone`);
   - в открывшемся фильтре выбрать действия и нажать **🟢 Включить**.

   Кнопка **🧪 Проверить текст** показывает, сработает ли фильтр на конкретной
   заявке.
4. **📣 Рассылки → ➕**:
   - выбрать шаблоны, чаты, интервал и паузу;
   - нажать **▶️ Запустить сейчас** или **🟢 Включить расписание**.

Кнопка **⏸ Пауза** сразу останавливает и фильтры, и рассылки.

## Почему не зависает

- Обработчик новых сообщений сверяет текст с правилами, заранее
  скомпилированными в памяти: на каждое сообщение нет ни одного запроса к базе.
  Вся работа по совпадению уходит в фоновую задачу.
- Исходящие отправки идут через одну очередь с паузами: ЛС отдельно, рассылки по
  одной. Так меньше риск флуда и спам-блока. На `PeerFlood` авто-ЛС
  приостанавливаются на час, на `FloodWait` юзербот ждёт и повторяет.
- Медиа рассылки загружается один раз, дальше переиспользуется уже загруженный
  файл.
- SQLite: WAL, `synchronous=NORMAL`, индексы под расписание, журналы и фильтры.
  Журналы старше N дней удаляются автоматически (по умолчанию 30, меняется в
  настройках).
- Если связь пропала, юзербот сам переподключается, а админка продолжает
  работать и сообщает о проблеме.

## Структура

```
main.py                  запуск юзербота и админки
login.py                 создание отдельной сессии
app/db.py                схема БД, индексы, настройки
app/userbot/             Telethon: мониторинг, ЛС, рассылки, фильтры
app/admin/               aiogram: меню, разделы, кнопки
tests/                   тесты фильтров и тихих часов (pytest)
```
