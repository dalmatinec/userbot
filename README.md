# Карамелька 💗

Сайт-сюрприз: вход по паролю, счётчик «мы вместе», плеер с нашими песнями, карточки «почему ты», письма «открой, когда…», мини-игра и финальный вопрос.

- `site/config.js` — все тексты, даты и пароль
- `music/` — песни (как называть файлы, смотри `music/README.md`)
- `deploy/install.sh` — установка на сервер одной командой

## Запуск на сервере (Ubuntu/Debian, от root)

```bash
curl -fsSL https://raw.githubusercontent.com/dalmatinec/userbot/main/deploy/install.sh | bash
```

Скрипт ставит nginx, выпускает бесплатный HTTPS-сертификат Let's Encrypt прямо на IP (без домена) и сам продлевает его. Каждые 2 минуты сайт подтягивает изменения из GitHub: загрузил песню или поменял текст, и через пару минут это уже на сайте.

Свой сертификат уже есть:

```bash
CERT=/путь/fullchain.pem KEY=/путь/privkey.pem bash install.sh
```
