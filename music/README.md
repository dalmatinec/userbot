# Песни

Просто закинь сюда mp3, сайт подхватит их сам (сервер подтягивает изменения из GitHub раз в 2 минуты).

**Название файла = название песни на сайте.** Пример: `Тима Белорусских - Мокрые кроссы.mp3`.

**Порядок.** Песни идут по алфавиту. Чтобы задать свой порядок, поставь номер в начале: `01 Артист - Песня.mp3`, `02 ...`. Номер на сайте не покажется.

**Подписи (по желанию).** Файл `captions.txt` в этой папке, строка на песню, через `|`:

```
01 Артист - Песня | под неё мы впервые танцевали
02 Артист - Песня | включай, когда скучаешь
```

Слева имя файла без `.mp3`, справа подпись.

Подходят форматы: mp3, m4a, ogg, opus, wav, flac. Размер одного файла на GitHub: до 100 МБ.
